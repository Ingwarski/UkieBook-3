# Handoff: UkieBook — Каталог (візуальна система «Аврора · пастельна», варіант 7b)

## Overview
UkieBook — українська платформа самопублікацій і онлайн-книгарня. Цей пакет фіксує **затверджений візуальний напрям** для клієнтської частини (каталог S-01 та наскрізні патерни: хедер, «стрічка формули», книжкові обкладинки). Напрям — **«Аврора · пастельна» (варіант 7b)**: тепла пастельна оболонка з мʼяким mesh-градієнтом, скляні (glassmorphism) поверхні, обкладинки книжок як єдине насичене джерело кольору, і сигнатурна «стрічка формули» винагороди автора **6 / 65,8 / 28,2**.

Цей екран — вітрина системи. Решта екранів продукту (сторінка книжки S-02, кошик S-04, бібліотека S-07, кабінет автора S-10…S-17, адмінка S-18…S-21) ще належить збудувати за `docs/screen-map.md` і `docs/wireframes.md`, застосовуючи описані тут токени й патерни.

## About the Design Files
Файли в цьому пакеті — це **дизайн-референс, зроблений в HTML** (прототип, що показує задуманий вигляд і поведінку), а **не продакшн-код для копіювання**. Завдання розробника — **відтворити цей дизайн у наявному середовищі цільової кодової бази** (React / Vue / Next / SwiftUI тощо), використовуючи її усталені патерни, компоненти й бібліотеки. Оскільки кодова база UkieBook порожня, потрібно **обрати доречний фреймворк** (рекомендація: React + TypeScript, адаптивний веб) і реалізувати дизайн там. `ukiebook-catalog.html` можна відкрити у браузері як живий еталон вигляду й наведень (hover).

Джерело прототипу в цьому проєкті: `UkieBook Design Options.dc.html`, секція з `id="7b"` (та фінальні правки розмірів/відступів у турні 9, які підтверджують масштаб обкладинок).

## Fidelity
**High-fidelity (hifi).** Кольори, типографіка, відступи, радіуси, тіні й наведення — фінальні. Відтворювати попіксельно засобами наявної дизайн-системи кодової бази. Єдине застереження: значення токенів у SDD позначені як «робочі до затвердження прототипу» — цей прототип їх і затверджує (окрім перевірки ліцензій шрифтів, див. Assets).

## Screens / Views

### Каталог / Home (S-01, маршрут `/`)
- **Purpose**: покупець шукає й обирає українську електронну книжку; автор бачить запрошення публікуватися.
- **Layout** (десктоп, контент 1220px, центрований):
  1. **Хедер** (`header.nav`) — горизонтальний flex, `padding:16px 40px`, `gap:26px`. Ліворуч логотип, далі навігація, праворуч (у `margin-left:auto` контейнері, `gap:14px`) — поле пошуку + кнопка кошика.
  2. **Хіро** (`.hero`) — центрований блок, `padding:46px 40px 18px`: заголовок H1 у два рядки (другий — градієнтний текст) + підзаголовок.
  3. **«Полиця» обкладинок** (`.shelf`) — flex-рядок, `justify-content:center`, `align-items:flex-end`, `gap:26px`, фіксована висота 270px; 5 обкладинок «левітують» на різній висоті (`translateY`) з невеликим нахилом (`rotate`).
  4. **Картки-плитки** (`.cards`) — CSS grid `repeat(4,1fr)`, `gap:18px`, `padding:34px 40px 8px`; кожна картка — скляна, обкладинка-мініатюра ліворуч + метадані праворуч.
  5. **Стрічка формули** (`.formula`) — скляний блок, `margin:26px 40px 40px`, `border-radius:26px`; ліворуч підпис, праворуч горизонтальна смуга, поділена 6% / 65,8% / 28,2%.
- **Пункти 1–3 лежать на «авроровому» фоні** (`.aurora` з `::before` mesh-градієнтом); картки й формула — на суцільному `--bg`.

#### Компоненти

**Логотип** — «Ukie**Book**», `font-weight:800`, `font-size:21px`, `letter-spacing:-0.03em`; частина «Book» кольором `--accent` (#B26BD6).

**Навігація** — 4 пункти, `font-size:14px`, `font-weight:500`, колір `--muted`; активний пункт — `--text` + `font-weight:600`. Пункти: Каталог (активний) · Жанри · Знижки · Авторам.

**Поле пошуку** (`.search`) — скляна «пігулка»: `background:rgba(255,255,255,.7)`, `border:1px solid rgba(46,38,33,.06)`, `border-radius:99px`, `padding:10px 18px`, `backdrop-filter:blur(10px)`, ширина 240px; плейсхолдер «⌕ Назва або автор…» кольором #A38F82, `13.5px`.

**Кнопка кошика** (`.cart`) — скляне коло 40×40, ті самі скляні токени; бейдж-лічильник у правому верхньому куті: `background:--accent`, білий текст, `font-size:10px`, `font-weight:700`, `padding:2px 6px`, `border-radius:99px`.

**Заголовок хіро** — «Затишні вечори» / «з українською книжкою». `font-weight:700`, `font-size:56px`, `line-height:1.02`, `letter-spacing:-0.035em`. Другий рядок — градієнтний текст: `linear-gradient(90deg,#E08AB0,#B26BD6 55%,#E8A04B)` через `background-clip:text`. Підзаголовок — `--muted`, `15.5px`, «EPUB і MOBI одразу в бібліотеку. 65,8% — автору.»

**Обкладинка книжки** (`.cover`, «полиця») — 138×207 (aspect-ratio 2:3), `border-radius:16px`, `padding:14px 12px`, тінь `0 24px 44px rgba(178,107,214,.24)`. Вміст: жанр (uppercase, 9px, `opacity:.7`) зверху; назва (`font-weight:800`, 15px) і автор (uppercase, 9px) — розподілені `space-between`. Колір фону і тексту — індивідуальні для кожної книжки (див. дані нижче). **Обкладинки завжди 2:3, без рамок — це «герой» кольору.**
- Позиції «левітації» (translateY / rotate) зліва направо: `-6/-2°`, `-14/-2°`, `-30/-3°` (центральна — «Місто на воді»), `+10/+2°`, `+18/+3°`.

**Картка-плитка** (`.card`) — скляна: `background:rgba(255,255,255,.8)`, `border:1px solid rgba(46,38,33,.05)`, `border-radius:22px`, `padding:16px`, тінь `0 8px 22px rgba(178,107,214,.1)`, flex `gap:14px`. Мініатюра обкладинки 64px шириною (2:3), `border-radius:12px`. Метадані: назва (`font-weight:700`, 14px), автор (#A38F82, 12px), ціна (`font-weight:800`, 14.5px, `tabular-nums`, «210 грн»).

**Стрічка формули** (`.formula` + `.bar`) — підпис «Прозора формула: з кожних 100 грн» (`font-weight:700`, 19px). Смуга висотою 44px, `border-radius:99px`, три сегменти:
- `6%` — податки: `background:#F7E7DE`, текст «6».
- `65,8%` — автору: `background:linear-gradient(90deg,#B26BD6,#E08AB0)`, білий, `font-weight:800`, «65,8 — автору».
- `28,2%` — платформа: `background:#F6E4D2`, колір #9A6438, «28,2».
Усі числа — `font-variant-numeric:tabular-nums`.

## Interactions & Behavior
- **Hover на обкладинці** (`.cover`) — `transform:translateY(-16px)`, перехід `.18s ease-out` (перекриває базовий левітаційний translate; у продакшні реалізувати через окремий шар трансформації, щоб hover не конфліктував із базовим `rotate`).
- **Hover на картці** (`.card`) — `transform:translateY(-4px)`, `.18s ease-out`.
- **Hover на посиланнях** — колір `--accent`.
- **Кліки/навігація** (реалізувати за `docs/screen-map.md`): обкладинка/картка → сторінка книжки `/books/{id}` (S-02); кошик → `/cart` (S-04); «Авторам» → онбординг автора / майстер публікації.
- **Мікро-переходи** — лише функціональні, 150–200ms ease-out (SDD Interaction Primitives). Переходи сторінок — без анімацій.
- **Responsive** (за `docs/wireframes.md` Responsive Notes): сітка карток 4 → 2 (планшет) → 1–2 (мобільний); «полиця» обкладинок на вузьких екранах стає горизонтальним скролом або 2–3 видимими; фільтри — у шторку; хедер тримає пошук/кошик за один клік. Цілі дотику ≥44px.

## State Management
Для повного каталогу знадобиться:
- `books` — список книжок (назва, автор, жанр, ціна, стара ціна, % знижки, рейтинг, к-сть відгуків, кольори обкладинки або URL обкладинки).
- `filters` — жанр, «зі знижкою», сортування; `query` — рядок пошуку.
- `cartCount` — к-сть позицій у кошику (бейдж).
- `pagination` / `isLoading` / `error` — для станів завантаження, порожнього результату, помилки (SDD State Patterns: скелетони повторюють геометрію зони, порожні стани — пояснення + CTA, помилки — інлайн із повтором).
- `session`/`role` — гість / покупець / автор (керує пунктами меню й доступом до `/author/*`).
Дані каталогу — з бекенд-API (поза цим пакетом).

## Assets
- **Шрифт**: Golos Text з Google Fonts (`https://fonts.googleapis.com/css2?family=Golos+Text`). SFOL/відкрита ліцензія — **підтвердити ліцензію перед продакшн-хостингом шрифтів** (SDD OQ-DB1); fallback — системний стек.
- **Обкладинки книжок**: у прототипі — кольорові плейсхолдери з назвою/автором. У продукті замінюються реальними завантаженими обкладинками (2:3). Якщо автор не завантажив — система генерує просту обкладинку з назви/автора/жанру (SDD FR-PUB-5).
- **Іконки**: пошук (⌕) і кошик (🛒) — тимчасові гліфи; замінити на іконки дизайн-системи кодової бази (лінійні, нейтральні).
- **OAuth-кнопки** (на екранах входу, не тут): Google/Facebook — за брендбуками провайдерів, без перефарбовування.
